# Documentation archive

This directory contains historical project documentation, not current
implementation truth. A file belongs here when its plan or handoff has been
completed, superseded, or replaced by a narrower current-state record.

Every archived Markdown file should begin with an ARCHIVED header that names:

- the archive date and why the file is historical;
- the live successor, if one exists; and
- any important evidence or design rationale the file still preserves.

Do not delete dated experiment packets or raw receipts just because their
conclusion changed. Keep their branch, revision, matchup, and
canonical/non-canonical status intact. When a historical document links to an
old path, prefer updating links in living docs; old prose may retain literal
paths as provenance.

Current implementation facts live in [the documentation index](../README.md)
and in the current-state pages it lists. Design authority history is under
[design_docs/archive/](../../design_docs/archive/).
