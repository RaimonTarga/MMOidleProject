diffing, not by reading report prose. Companion to
[the adoption review](bot-balance-mob-adoption-review.md), which carries the provenance and
rationale; this file carries the numbers a patch would actually write.

**Status of every row below: `selected` — retained by the campaign, verified against current
source, NOT applied.** Production adoption needs explicit approval. Nothing here is authorized
by this document.

## How to read this

These are **final authored values**, with every overlay layer already flattened. Do not
re-apply an intermediate table on top of them, and do not copy a `ready.json` HP into an
authored field: READY values are post-modifier runtime values.

**One composition trap.** Two retained branches both include the Durability22 base layer, and
they disagree about `dune-basilisk`:

- the Desert branch (D26) applies the base layer and then doubles `dune-basilisk` again → **9006**
- the Mountain branch (D29 T4) applies the base layer and leaves it at 4503

A naive last-writer-wins pass over the installers silently produces 4503 and drops the later
Desert decision. **The retained value is 9006.** The table below states it correctly.

## Defence coupling — exact, not rounded

Every coupled field preserves an **absolute** budget by scaling the percentage inversely.
Author the exact expression or carry full precision:

| Species | Absolute budget | Authored percentage |
|---|---|---|
| `granite-mammoth` | ward `0.25 × 1150 = 287.5` | `0.25 * 1150 / 13800` = 1/48 = 0.0208333… — the rounded `0.0208` gives 287.04, short by 0.46 |
| `glacial-direbear` | shield `0.22 × 1221 = 268.62` | `0.22 * 1221 / 4884` = 0.055 exactly |

The Durability22 installer also rescales every `shield` action nested inside `monsterAbilities`
by `before/after`. A patch must carry those too — a dash in a summary row must not hide a real
coupling. `granite-titan`'s Granite Barrier is **not** rescaled: its HP does not move, only its
attack, so `wardPct` stays 0.25.

## Proposed patch shape

One commit, in this order, so no layer is applied twice:

1. Write the **final** HP and attack values above directly into
   `shared/src/data/monsters/*.monsters.ts`. Do not run installers against production data.
2. Write the two coupled defence fields as exact expressions, with a comment naming the
   absolute budget they preserve.
3. Retire or rebase the baseline assertions that deliberately expect pre-adoption values —
   every `assert.equal(d.stats.hp, before, '… baseline drift')` in the retained installers will
   now fire, which is correct and expected. Historical frozen studies keep their own revisions
   and must not be edited.
4. Add one current-source regression: a same-role tier-ladder check asserting monotonicity
   across T2 → T3 → T4 for the affected lineages, plus the two absolute defence budgets.
5. Re-run the focused benches that reference these species; do not re-run resolved grids
   (Trench 16800 vs 21000, universal Focus Elites, Forest/Volcano ladders).

## Jungle, added 2026-09-18 after Durability34

Durability34 tested the HP-only package across 72 observations, six roots, two nodes, both arms
full-window with zero deaths. Measured clean body TTK moved as intended and the fast bodies did
not:

| Species | Clean TTK control → candidate | Fast bodies |
|---|---|---|
| `emerald-constrictor` | 3.27 s → 6.50 s | `thornback-lizard` 1.90 → 1.90 s |
| `apex-silverback` | 2.85 s → 5.95 s | `hunting-panther` 1.85 → 1.80 s |

Apex ramp exposure rose with the longer body (ramped share 81.9% → 91.7%, p90 gross 124 → 137),
measured from existing damage evidence rather than asserted.

**Explicitly unverified: the cross-tier ladder.** There is no measured T3 TTK anywhere in this
campaign — the "2.90 s T3 anchor" in the D34 report was the T4 apex baseline, and the real T3
citation was authored HP 2090. Authored HP ordering is **not** the acceptance test for a
duration ladder. Before Jungle pacing is called complete, compare compatible existing T2/T3
role-timing evidence against T4 and, where it is absent, fold one limited check into the
consolidated regression. If the actual duration ladder is still reversed, make one deliberate
revision rather than re-deriving from authored HP.
