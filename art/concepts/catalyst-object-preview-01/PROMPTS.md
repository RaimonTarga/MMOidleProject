# Catalyst object preview 01

Preview-only exploration generated with the built-in image workflow on
2026-07-24. Nothing in this directory is wired into the atlas.

## Master prompt

Create one tangible, freestanding cyan catalyst crystal for a fantasy idle-RPG
HUD. The crystal is tall and narrow, with a pointed top, a shorter lower point,
broad shoulders, a restrained near-black edge, and exactly three large opaque
facets. It has no rune, symbol, socket, frame, pedestal, particles, aura, cast
shadow, or text. It must remain object-like at an 18px display size.

The source used a flat `#ff00ff` chroma background and the old neutral catalyst
only as a proportion reference.

## Variant strategy

Only one crystal geometry was generated. The five variants are deterministic
hue rotations of that master, preserving identical pixels, lighting, facets,
and silhouette:

- Alacrity: cyan
- Brutality: red
- Blight: green
- Volatility: purple
- Predation: amber

`hud-context-preview.png` shows each 32px source enlarged with nearest-neighbor
scaling and again at the literal 18px HUD display size.
