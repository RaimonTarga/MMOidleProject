# Modifier symbol set 02

Generated with the built-in image workflow on 2026-07-24, using
`dungeon-symbol-01/dungeon-skull-master.png` as the approved style reference.

Shared constraints:

- one dominant ivory silhouette on a flat `#00ff00` chroma background;
- near-black contour roughly one sixth of the symbol width;
- hard, flat shapes with no shading, texture, frame, text, or secondary effects;
- generous outer padding and explicit readability at 8–16 pixels.

Family silhouettes:

- Alacrity: exactly two broad forward chevrons.
- Brutality: one blunt front-facing hammer with one central crack.
- Blight: one toxic droplet with one upper-right bite and one central void.
- Volatility: one four-point crystal with one central zigzag split.
- Predation: one almond hunting eye with one vertical slit pupil.

The transparent outputs were normalized onto 256x256 masters and reduced to
16x16 production frames with Lanczos resampling. `set-comparison.png` records
the literal-size acceptance check.
