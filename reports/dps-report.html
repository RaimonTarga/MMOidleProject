Unlock model: T1 class root, T2 frame, T3 close/far range, T4 path/spec. Weapons: each report tier's non-tutorial weapons at +3. Targets use biome spawn pools one tier below the report tier, excluding tutorial/test monsters. Mechanics with runtime state are represented as deterministic steady-state estimates and are called out in row notes. Run with --exclude-conduit to omit Conduit and its subclasses.
