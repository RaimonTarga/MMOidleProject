## Six-root measured findings

- Striker: all primary cells cap-ended except one balanced Jungle death and four early Desert deaths in light/balanced. Striker heavy Desert survived both seeds and adopted the rune; the light/balanced deaths never reached adoption. Preserve the frame/package question and do not label the pre-adoption Desert deaths a rune failure.
- Squire: all primary cells cap-ended except balanced Jungle seed 101009. The three Desert frames survived both seeds, paid for and equipped Focus Lowest HP, and showed repeated native guard use. This is a strong defensive reference in the fixed packet, not a universal class ranking.
- Apprentice: all 42 primary A/D rows cap-ended. Plains and Forest delivery was strong relative to the slower Mountain/Cave frames, while the Desert rows remained ranged and untreated. No T2 sibling received the T3 Break Free path.
- Slinger: all primary rows cap-ended. The class maintained a broad biome footprint, and the Stinger Rapier primary beat Mirebrand in all four W2 matched cells. Retain this as a named whole-package candidate only.
- Conduit: 35/36 primary rows cap-ended; the single death was balanced Jungle at 296.4 s from DoT exposure. Conduit showed low delivery in several slow fixtures while retaining survival, so the next question is formation/owner payment/delivery instrumentation rather than an automatic global nerf.
- Spirit: all 42 primary A/D rows cap-ended. Spirit provided stable local references across the map, with strong Plains/Forest/Swamp work and no deaths. This is evidence to retain the class value and investigate niches, not a cross-biome winner claim.
