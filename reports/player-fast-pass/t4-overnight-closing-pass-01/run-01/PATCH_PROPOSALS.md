# T4 overnight closing pass 01 — patch proposals

## Decision

No numerical patch proposal is supported by this run, and no patch was adopted.

The run is a synthetic package screen. Control and candidate are the same measured source, the largest survival differences are fixture-shaped (Volcanic and Desert versus Tundra), and the optional contrasts are whole-package one-field build changes. The retained telemetry does not provide a counterfactual class-coefficient estimate, source-specific healing/overheal, or a causal decomposition of Heat, targeting, formation, or owner payments.

This is an explicit zero-proposal result, not a missing artifact. The measured values below are review anchors and rejected hypotheses, not requested edits.
